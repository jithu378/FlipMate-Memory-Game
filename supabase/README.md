# Supabase backend (not connected in this starter)

This folder is reserved for the online multiplayer backend. The frontend currently has no Supabase client and the online room flow is explicitly a demo.

Before shipping online features, implement and review:
- Authentication and profiles
- Room membership and access policies
- Server-authoritative game transitions
- Realtime event distribution
- Validated result submission
- Leaderboard queries and RLS tests

Do not deploy permissive policies or trust score values supplied by a browser.
